# Plan 01-02: SQLite Schema Migrations & Storage Repositories

## Goal
Implement the SQLite database initialization, automated table migrations, foreign key PRAGMA enforcement, and CRUD repository methods for Clients, Service Tickets, and Financial Transactions.

## Proposed Changes

### Database Connection & Migration (`internal/store/sqlite/db.go`, `migrations.go`)
- `OpenDB(path string) (*sql.DB, error)` configuring connection pool (`SetMaxOpenConns(1)` for safe SQLite single-writer semantics) and executing `PRAGMA foreign_keys = ON;`, `PRAGMA journal_mode = WAL;`, `PRAGMA busy_timeout = 5000;`.
- Schema definition:
  - `clients`: `id INTEGER PRIMARY KEY AUTOINCREMENT`, `name TEXT NOT NULL`, `phone TEXT NOT NULL`, `bike_details TEXT`, `notes TEXT`, `created_at DATETIME`, `updated_at DATETIME`
  - `service_tickets`: `id INTEGER PRIMARY KEY AUTOINCREMENT`, `client_id INTEGER NOT NULL REFERENCES clients(id) ON DELETE CASCADE`, `description TEXT NOT NULL`, `status TEXT NOT NULL`, `priority TEXT NOT NULL`, `estimated_cost REAL`, `final_cost REAL`, `created_at DATETIME`, `updated_at DATETIME`, `completed_at DATETIME`
  - `financial_transactions`: `id INTEGER PRIMARY KEY AUTOINCREMENT`, `ticket_id INTEGER REFERENCES service_tickets(id) ON DELETE SET NULL`, `type TEXT NOT NULL`, `category TEXT NOT NULL`, `amount REAL NOT NULL`, `notes TEXT`, `date DATETIME NOT NULL`
- Indices on `service_tickets(status)`, `service_tickets(client_id)`, and `financial_transactions(date)`.

### Store Repositories (`client_repo.go`, `ticket_repo.go`, `finance_repo.go`)
- `ClientRepository`: `CreateClient`, `GetClientByID`, `ListClients`, `SearchClients(query)`
- `TicketRepository`: `CreateTicket`, `GetTicketByID`, `ListTickets(filter Status)`, `UpdateTicketStatus(id, status)`
- `FinanceRepository`: `CreateTransaction`, `ListTransactions(from, to)`, `GetMonthlySummary(year, month)`

### Comprehensive Tests (`store_test.go`)
- In-memory SQLite tests (`:memory:`) testing full lifecycle:
  - Creating a client
  - Creating a service ticket for client
  - Advancing status through all 5 states
  - Recording income/expense transactions
  - Verifying monthly balance aggregation
