# Plan 01-01: Go Project Initialization, Config & Domain Entities

## Goal
Initialize the Go module (`github.com/ratitu/pelotonServiceManager` or `peloton`), install `modernc.org/sqlite` and core testing dependencies, implement the configuration resolution for XDG database paths and environment overrides, and define domain models and status enums for Clients, Service Tickets, and Financial Transactions.

## Proposed Changes

### Go Module Initialization
- Run `go mod init peloton`
- Add `modernc.org/sqlite` dependency
- Establish clean directory hierarchy:
  - `cmd/peloton/`
  - `internal/config/`
  - `internal/domain/`
  - `internal/store/sqlite/`

### Configuration Package (`internal/config/config.go`)
- `Config` struct holding `DBPath`, `Port`, `Host`.
- Resolution order: CLI flag override -> `PELOTON_DB_PATH` env var -> `~/.local/share/peloton/peloton.db` (XDG data home) -> `./peloton.db` fallback.
- Directory auto-creation helper (`EnsureDataDir`).

### Domain Models (`internal/domain/models.go`)
- `Client` struct: `ID` (int64), `Name`, `Phone`, `BikeDetails`, `Notes`, `CreatedAt`, `UpdatedAt`.
- `TicketStatus` enum string:
  - `StatusPending = "Pending"`
  - `StatusInProgress = "In Progress"`
  - `StatusWaitingParts = "Waiting for Parts"`
  - `StatusReadyPickup = "Ready for Pickup"`
  - `StatusCompleted = "Completed"`
- `IsValidStatus(status TicketStatus) bool` validation method.
- `ServiceTicket` struct: `ID` (int64), `ClientID` (int64), `Description`, `Status` (`TicketStatus`), `Priority`, `EstimatedCost` (float64), `FinalCost` (float64), `CreatedAt`, `UpdatedAt`, `CompletedAt` (*time.Time).
- `TransactionType` enum: `INCOME` vs `EXPENSE`.
- `FinancialTransaction` struct: `ID` (int64), `TicketID` (*int64), `Type` (`TransactionType`), `Category`, `Amount` (float64), `Notes`, `Date` (time.Time).
