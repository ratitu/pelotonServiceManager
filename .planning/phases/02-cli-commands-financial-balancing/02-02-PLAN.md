# Plan 02-02: Financial Logging & Monthly Summary CLI Commands

## Goal
Implement CLI subcommands for financial transaction logging (`peloton finance income` and `peloton finance expense`) and monthly balance reporting (`peloton finance summary`) displaying income, expense breakdown, and net profit.

## Proposed Changes

### Financial Subcommands (`internal/cli/finance.go`)
- `peloton finance income --amount <val> [--category <cat>] [--ticket <id>] [--notes <note>] [--date YYYY-MM-DD]`
  - Validates positive amount.
  - Automatically associates with ticket if provided.
  - Defaults category to `Service` and date to current day.
- `peloton finance expense --amount <val> [--category <cat>] [--notes <note>] [--date YYYY-MM-DD]`
  - Defaults category to `Parts` or `Supplies`.
- `peloton finance summary [--month 1-12] [--year 2026]`
  - Defaults to current month and year.
  - Fetches summary using `FinanceRepository.GetMonthlySummary`.
  - Formats output card with:
    - Period (e.g. `November 2026`)
    - Completed Services Count
    - Total Cash In (Income)
    - Total Cash Out (Expenses)
    - Net Profit (with visual indicator: positive/profit vs negative/deficit)
- `peloton finance list [--from YYYY-MM-DD] [--to YYYY-MM-DD]`
  - Lists individual transactions in tabular format.

### Integration Tests (`internal/cli/finance_test.go`)
- Test logging income associated with completed service ticket.
- Test logging general workshop parts expense.
- Test calculating and rendering monthly summary card.
- Test date parsing and validation errors.
