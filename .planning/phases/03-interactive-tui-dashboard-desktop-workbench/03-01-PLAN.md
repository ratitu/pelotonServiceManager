# Plan 03-01: Interactive TUI Dashboard Core & Column Queue View

## Goal
Integrate Charm `bubbletea` and `lipgloss` to build an interactive, responsive terminal user interface (TUI) displaying the 5 lifecycle queues (Pending, In Progress, Waiting for Parts, Ready for Pickup, Completed) in visual columns with keyboard navigation.

## Proposed Changes

### Dependencies (`go.mod`)
- Add `github.com/charmbracelet/bubbletea@v0.25.0`
- Add `github.com/charmbracelet/lipgloss@v0.9.1`

### Styling & Theme (`internal/tui/styles.go`)
- Lipgloss styles for:
  - Column headers (with status color coding: Yellow for Pending, Blue for In Progress, Orange for Waiting for Parts, Green for Ready for Pickup, Gray/Dim for Completed)
  - Ticket cards with priority indicators (`[High]`, `[Urgent]`)
  - Cursor / active selection highlighting
  - Header & status bar with key hints (`[←/→] Switch Column  [↑/↓] Select Ticket  [Enter] Inspect  [q] Quit`)

### Architecture (`internal/tui/model.go`, `update.go`, `view.go`)
- `Model` struct:
  - Repositories: `TicketRepo`, `ClientRepo`, `FinanceRepo`
  - Columns: array of 5 columns, each containing a list of `domain.ServiceTicket`
  - Navigation state: `activeColumnIndex`, `selectedTicketIndex`
  - Window dimensions: `width`, `height` with responsive column resizing
- Keybindings:
  - `h`/`l`, `Left`/`Right`, `Tab`/`Shift-Tab`: Change column
  - `j`/`k`, `Up`/`Down`: Scroll ticket selection in current column
  - `r`: Refresh tickets from SQLite store
  - `q`, `Ctrl+C`: Exit TUI
